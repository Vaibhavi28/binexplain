 # Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in BinExplain itself (not in
binaries you analyze with it), please report it responsibly.

Email: hello@binexplain.com
Subject: "BinExplain Security Report"

Please do not open a public GitHub issue for security vulnerabilities.

## In Scope

- Authentication or authorization bypasses
- Server-side request forgery
- Remote code execution
- Path traversal attacks
- Injection vulnerabilities
- Bypass of file validation that could lead to execution

## Out of Scope

- Vulnerabilities in uploaded binaries themselves
- Social engineering
- Denial of service attacks on the free-tier infrastructure

## Our Commitments

- We will acknowledge reports within 5 business days
- We will not take legal action against good-faith security researchers
- Uploaded files are never executed — static analysis only
- Files are deleted immediately after analysis
