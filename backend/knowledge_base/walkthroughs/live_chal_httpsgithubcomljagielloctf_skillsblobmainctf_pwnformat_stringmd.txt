Overwriting both lets you redirect any printf format specifier to an arbitrary function. Combined with _fortify_fail (which prints __libc_argv[0] ), this turns a buffer overflow into an info leak without needing a format string vulnerability. When to recognize: Buffer overflow that can reach glibc globals but no direct format string vulnerability. The target binary calls printf with format specifiers after the overflow. Useful when the goal is information exfiltration (flag leak) rather than code execution.
