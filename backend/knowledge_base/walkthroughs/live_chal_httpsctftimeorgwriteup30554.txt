We also need to pay attention to the number of character written so far in general, because the use of %n specifier doesn't reset the count. As last thing, we have to ensure that the format string payload is shorter than 128 (see decompiled code). A possible format string, for a given libc base address: ``` %26739c%1$n%46557c%8$hn%3894c%9$hn%21044c%10$hn%32838c%11$hn ``` We managed to get the shell, and the flag, with this exploit.
