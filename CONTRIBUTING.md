# Contributing to BinExplain

BinExplain is source-available under CC BY-NC-ND 4.0. Direct code contributions
via pull request are not accepted at this time. However, contributions in the
following forms are very welcome:

## How to Contribute

### Report a Bug
Open an issue at github.com/Vaibhavi28/binexplain/issues
Include: what happened, what you expected, your binary type and size,
your browser, and steps to reproduce.

### Request a Feature
Open an issue with the label "enhancement". Describe what problem it
solves for CTF players and how it would fit into the existing interface.

### Share a CTF Writeup
If you solved a challenge using BinExplain and want to add your writeup
to the knowledge base, email hello@binexplain.com with the writeup text.
Writeups that are added will be credited.

### General Questions
For any other questions or feedback, email hello@binexplain.com.

## Security Issues
For security vulnerabilities, email hello@binexplain.com directly.
Do not open a public issue for security reports.

## Code of Conduct
Be respectful. This tool was built for education and the CTF community.
